## 1. Goal

Set up the course environment and practice the first step of every ML project: loading,
auditing, cleaning, and summarizing a messy tabular dataset with pandas.

Dataset: `data/cafe_sales.csv` — 412 rows of (synthetic) cafe order records containing
duplicated rows, missing values, prices stored as strings ("4,500"), and bulk-order outliers.
**No download needed; the data ships in this folder.**
